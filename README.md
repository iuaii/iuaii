## 🚀 Featured Projects

### 1. NavSVLM — Vision-Language Model for Assistive Navigation

Developed a vision-language model for assistive navigation, combining visual features and object motion information to generate guidance for visually impaired users.

**Key achievements:**
- Implemented Q-Former compression from 256 to 32 visual tokens.
- Reduced the visual token count by 87.5%.
- Integrated trajectory features for up to 6 tracked objects.

**Technologies:** Python, PyTorch, Hugging Face Transformers, InternVL-2B, InstructBLIP Q-Former, PEFT/QLoRA, OpenCV, Kalman Filter.
